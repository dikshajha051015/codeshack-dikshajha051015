# CODESHACK DEVELOPER HANDBOOK:
Welcome to my CodeShack Developer Handbook, created as part of the CodeShack Club's Week 1 task on Git and GitHub CLI.

# About The Project:
The purpose of this project is to learn and practise the fundamentals of Git and GitHub using command-line instructions.
This handbook serves as a personal reference for useful Git commands, version control concepts, branching, and collaboration.

# Objectives:
--> Understand the basics of Git and GitHub.
--> Learn how to initialize and manage a Git repository.
--> Practise staging, committing, and tracking changes.
--> Understand branches and how developers work independently.
--> Learn how to push and pull changes between local and remote repositories.
--> Document useful Git commands with examples.
--> Build good habits for collaborating on software projects.

# Tools Used:
1. Git: Version control system for tracking changes.
2. GitHub: Online platform for hosting repositories and collaborating.
3. Visual Studio Code: Code editor used to create and manage files.
4. Markdown: Format used to write project documentation.
5. Git Bash/Terminal: Command-line interface used to execute Git commands.

# Project Structure:
codeshack-handbook/ 
|--README.md
|--git-notes.md

File Description:-
1) README.md - Introduces the project and explain its objectives.
2) git-notes.md - Documents useful Git commands and examples.

# What I Learned:
Through this project, I am learning how developers use Git to track their work, maintain project history, create branches, and collaborate with others.
I am also practising writing clear commit messages and keeping repositories organized.
